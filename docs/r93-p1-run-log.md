## 2. 配方（`docs/r93-p1-launch-recipe.md`）

- d24_c1 dense（288M active / Engram 220M）/ K=40k tokenizer（V=41,280）/ seq 8192
- **2^21 tokens/optimizer-step**（b1×8192×accum256，S3 判定 2^22 不免费）
- **8.0e9 tokens → 3,814 步**
- LR **8e-4**（S1 结论 0.7–1.0e-3 的中心），WSD warmup **30** / decay-start 0.9 / min-lr 0.1
- **z-loss 1e-4**（v2 快速路径，实测 +0.46% 步时）；**EMA 0.995**（每步，实测开销≈0）
- grad-clip 1.0，seed 1234，`--abort-on-nan`
- `--save-at-tokens 1b,2b,4b,6b`（mark ckpt 由 eval loop 评测后删除）

### 4c. 22:16 轨迹外推（用户问"还能达到目标吗"）

三个独立拟合（数据：1B/2B val bpb 1.2771/1.1897；训练 loss 曲线 135 点至 2.81B）：

| 拟合 | 斜率 | 8B 中段 bpb | 加 cooldown 0.03–0.08 后的最终 |
|---|---|---:|---:|
| val-bpb (1B,2B) | β=0.102 | 1.032 | **0.95–1.00** |
| 训练 loss 近 300 步 | β=0.086 | ~1.04 | ~0.96–1.01 |
| 全稳定段 loss | β=0.148（偏乐观，含早期陡段） | — | 0.86–0.91 |

**结论：目标 0.89 大概率达不到；现实预期 0.93–0.99（中心 ~0.95），与 nanochat 等算力线（0.94）基本持平或略差。**
`bpb<1.0`/`loss<3.0` 仍大概率能满足。

**为什么**：0.89 是从 P0b **短跑高 LR（2.9e-3）**曲线外推的；长跑（LR 8e-4）的中段轨迹天然更慢，
且我们的中段斜率只有 β≈0.09–0.10（参考曲线 0.15）。两种解释未区分：(a) 长跑策略的固有代价
（cooldown 后追回一部分）；(b) **LR 8e-4 偏低**导致收敛慢。干净判定需要 4B mark 的第 3 个 val 点。

**4B mark（预期 11-18 03:25）决策树**（已预注册）：
- 4B bpb ≤1.08：轨迹在变陡/符合预期 → **继续跑完**（最终预计 0.92–0.95）；
- 1.08–1.12：继续跑完，接受 ~0.95–0.99，作为"LR 保守"的单一变量证据；
- >1.12（差距继续扩大）：考虑**中段抢救**——从 4B ckpt 起做 3 臂 LR 短探针
  （0.2B tokens @ {8e-4(对照), 1.4e-3, 2.0e-3}，¥8，~2.7h），赢家 LR + 更长 cooldown
  （decay-start 0.8）重启剩余 3.8B tokens（重启成本 ≈ 继续跑的成本，¥52–55）。
  风险：fresh optimizer 动机会损失；收益需探针显著才值得。

### 4d. 4B mark（2026-11-18 03:34）与决策

**4B mark val bpb = 1.11755**（2B 1.1897 → 4B 1.1176，−0.0722；局部 β：1→2B 0.102、2→4B 0.090）。

三点拟合 `bpb = 1.2754·D_B^-0.0963` → 8B 中段 ≈ **1.044**；cooldown 补偿 0.04–0.08 →
**最终 8B bpb ≈ 0.96–1.01（中心 ~0.98）**。loss 曲线近 600 步拟合（β=0.077）给出同量级结论。

按预注册决策树：4B=1.1176 ∈ [1.08,1.12] → **继续跑完**；且余额 ¥<redacted>、剩余运行成本 ~¥<redacted>，
LR 探针+重启方案（≥¥60）不可负担。4B ckpt（1.21GB）已保留作保险（eval loop keep 模式生效）。

**与 P0b-final 参考的 gap 趋势（用户 08:35 追问）**：1B +0.0665 → 2B +0.1017 → 4B +0.1397 bpb，
单调扩大。注意参考点是"短跑高 LR 跑完 cooldown 的 val"，对低 LR 长跑的中段点本就不公平；
要看的量是我们自己曲线的斜率（三点拟合 β=0.096），据此 6B 中段 ≈1.073、8B 中段 ≈1.044 →
cooldown 后最终 ≈ **0.96–1.00**（中心 ~0.98）。gap 扩大本身正是"LR 8e-4 对 8B 偏低"的信号。

**结论更新**：目标 0.89 确定达不到；本次 8B 运行是"LR=8e-4 对长预算是否偏低"的干净单一变量证据，
预计最终明显慢于 P0b 短跑高 LR 曲线外推。主要教训：S1 的 LR 定律（2 点、短预算）向 8B 外推过于激进；
下次长预算应直接用小预算 2–3 臂 LR 扫描锚定（或 LR≈1.5e-3 起）。

### 4e. 6B mark + 并行 LR 探针结果（2026-11-18 ~12:30）

**6B mark val bpb = 1.09049**（4B 1.11755 → 6B 1.09049，−0.0271；局部 β 0.060）。
四点拟合 `bpb = 1.2718·D_B^-0.0893` → 8B 中段 **1.056**；cooldown 0.03/0.05/0.08 →
最终 **1.03 / 1.01 / 0.98**；EMA 再 −0.005~0.015 → **最终约 0.97–1.02（中心 ~1.00，loss ~3.08 nats）**。

**并行 LR 探针（第二台 5090，4B ckpt 起、fresh optimizer、每臂恒定 LR 跑 0.2B tokens @4.2B）**：

| LR | 4.2B val bpb | 相对对照 |
|---|---:|---:|
| **8e-4（对照）** | **1.1151** | — |
| 1.2e-3 | 1.1310 | +0.0159 |
| 1.8e-3 | 1.1593 | +0.0442 |
| 2.6e-3 | 1.1972 | +0.0821 |

**结论：LR 8e-4 不是瓶颈——提高 LR 单调变差（2.6e-3 差 0.082 bpb）。** 因此"LR 偏低"假设被否定；
之前与 P0b 参考线的差距来自参考曲线本身（短跑高 LR 的 final 点不能当作长跑中段的目标线）
+ 本配方在 8B tokens/288M active 下的真实收敛水平。探针总花费 ~¥12，探针实例已关机。
（注：probe 用 fresh optimizer，高 LR 臂受 Adam 重置影响偏大，但单调性和量级足够说明排序。）

**含义**：0.89 目标不可达是配方层面的结论，不是 LR 调参能救的；若追求更低 bpb，需要
更长训练/更大模型/KD（见 docs/r93-dense-plan.md §11 的路线与成本）。
