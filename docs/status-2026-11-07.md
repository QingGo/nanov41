## 3. Performance (RTX 5090, bf16, measured)

Training (d12, b16 × seq1024 graph, R69 stack):

| arm | tok/s | training MFU |
|---|---:|---:|
| E-none (P2) | 253.9k | **50.5 %** |
| E-default (P2) | 243.7k | **48.5 %** |
| P2b fallback stack | 230.6–241.7k | 45.9–48.1 % |

Eval / NLL (T0 head; batch × 1024):

| mode | b16 tok/s | b16 peak | b32 | eval MFU (b16) |
|---|---:|---:|---|---:|
| legacy full logits | 88.0k | 17.48 GB | OOM | 5.8 % |
| chunked NLL | 90.9k | 9.04 GB | 96.9k / 17.81 GB | 6.0 % (b32 6.4 %) |
| fused v3 NLL | **128.1k** | **3.24 GB** | int32 limit | **8.5 %** |

Older t141 eval measured 78.5k tok/s (5.2 % MFU).  T0 uses 15 M scored tokens → ~3 min/ckpt
legacy, ~2.4 min chunked, ~2 min fused.

Inference decode (real P2b checkpoint, RTX 4090, batch 1, 32 greedy tokens):
- reference **12.64 tok/s** → native Engram+MoE **13.26** → ref+fused mHC **18.12** →
  **native+fused mHC 19.34 tok/s** (1.53× vs reference); fused mHC is now the default because it
  is numerically free (100 % token agreement, T0 BPB −6e-6);
- quality of the native path: FP8 Engram tables (e4m3 + E8M0) change T0 macro BPB by **−6e-6**
  (1.922638 → 1.922632); native greedy agreement vs reference is 65 % only because a 0.6 B-token
  model has near-tied margins (tables alone on the torch path: 81.9 %);
- the decode step is **CPU launch-bound**: 1730 CUDA launches/step vs 3.86 ms/step GPU busy;
  component CPU shares attention 42 %, mHC+norm 31 %, small-M MoE 21 %, Engram 2 %;
- decode attention fast path (fused RMSNorm/RoPE/window+sparse-attention kernels): 100 % argmax
  agreement vs reference over 24 decode steps, e2e native stack 19.46 → **23.28 tok/s** (1.20×)
  and 1730 → 1019 launches/step; attention CPU 20.8 → 14.9 ms at ctx 512;
- Engram decode gather/dequant: **28.8–30.1 µs** vs torch **99.7–100.4 µs** (~3.4×), exact parity;
  hash decode parity 0;
- MoE small-M: 1.87× (T=1) to 6.28× (T=8) at the layer level; full-model CPU parity 4.8e-6;
- vLLM fallback real weights works but ~10.7 output tok/s eager; correctness only, not perf.

Loss/quality after 0.6 B:
- final train loss E-none 4.85–4.88, E-default 4.66–4.75;
- T0 macro BPB ~1.92–2.01, Marin phase-1 mix 1.425–1.480;
- Engram default beats none in all 3 seeds: phase-1 **−1.87 / −3.71 / −2.26 %**, macro
  −0.83 / −4.39 / −1.74 %; thin −0.95 %; thick regresses; d12e32 +0.23 % worse.
